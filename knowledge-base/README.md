# IVF App — Knowledge Base

Drop your research documents in this folder. These become the trusted sources
the app's assistant uses to answer questions.

## What to upload

Patient-facing documents from reliable sources, for example:

- Medication patient leaflets / instructions for use (Gonal-F, Menopur,
  Ovidrel, Cetrotide, Crinone, etc.)
- Clinic patient handbooks or protocol explanations
- Guides from professional bodies: HFEA (UK), ASRM (US), ESHRE (Europe),
  SBRA / Febrasgo (Brazil)
- Injection technique guides

## Accepted formats

PDF, Word (.docx), plain text (.txt), or Markdown (.md) all work.
If a source is a web page you can't download, create a text file with the
link in it (or just paste the link in the chat) and Claude will fetch it.

## Tips

- Prefer official/original sources over blogs or forums.
- Name files descriptively, e.g. `gonal-f-patient-leaflet-EN.pdf`.
- Note the language of each document if you're collecting in more than one
  language (the app can answer in the user's language regardless).
